# RadioBOSS Toolkit v0.3.1

This maintenance update brings RadioBOSS Library Cleaner 1.0.1 into the portable Toolkit.

## Changes

- Remembers the last selected RadioBOSS SQLite database path
- Reopens the file chooser in the previously used database folder
- Reports a saved path that is no longer available
- Keeps all existing Toolkit languages, including Romanian
- Never stores MySQL passwords or other database credentials
