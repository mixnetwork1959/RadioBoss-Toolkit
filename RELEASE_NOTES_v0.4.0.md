# RadioBOSS Toolkit v0.4.0

Freeware shop release preparation.

## Changes

- Broadcast Scheduler removed from the Toolkit package and launcher.
- Broadcast Scheduler is now prepared as a separate freeware product.
- Toolkit window opens centered on the monitor currently in use.
- Launcher uses a cleaner 2 × 2 card layout.
- SongSync card now has two equal-width buttons: **Sync now** and **Setup**.
- Offline help updated in English, German, Dutch, Bulgarian and Romanian.
- Toolkit build script no longer packages Broadcast Scheduler.
- Added a separate `build_broadcast_scheduler.bat` workflow.
- Added explicit freeware / free download labeling.

## Included Toolkit tools

- RadioBOSS Library Cleaner 1.0.1
- Silence Scanner GUI 1.0.0
- Auto Cutter GUI 1.0.0
- SongSync Engine 1.7.2

## Separate freeware product

RadioBOSS Broadcast Scheduler 4.5.1 is built and distributed separately.
