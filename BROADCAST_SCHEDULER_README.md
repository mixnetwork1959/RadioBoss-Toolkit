# RadioBOSS Broadcast Scheduler

Version 4.5.1

A free Windows utility for checking RadioBOSS scheduler profiles, reviewing conflicts and publishing a public calendar.

## Freeware

RadioBOSS Broadcast Scheduler is distributed as a **free download**.

## Main features

- Open and analyze RadioBOSS scheduler profiles (`*.sdl`)
- Review scheduled events and timing conflicts
- Filter event lists
- Work with weekday selections and event durations
- Generate a public schedule/calendar
- Multi-language interface
- Portable Windows application

## Installation

Extract the complete folder to a normal writable location, for example:

- `C:\RadioBOSS Broadcast Scheduler`
- `D:\RadioBOSS Broadcast Scheduler`

Do not place the application in protected Windows folders such as `C:\Program Files` or `C:\Windows` if you want settings and generated files to remain portable.

Start:

`RadioBOSS Broadcast Scheduler.exe`

On first start, select your RadioBOSS scheduler profile (`*.sdl`).
