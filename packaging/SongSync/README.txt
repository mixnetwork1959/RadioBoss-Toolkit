RadioBOSS Toolkit - SongSync packaging folder

Before running build_toolkit.bat, place the current SongSync Windows executables in this folder:

- RadioBOSS-SongSync.exe
- RadioBOSS-SongSync-Setup.exe

The Toolkit build script copies these files into:
RadioBOSS Toolkit\tools\SongSync\

Do not commit private configuration files, passwords, API credentials or customer data here.
