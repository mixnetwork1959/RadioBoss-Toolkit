# RadioBOSS Toolkit v0.2.4

This update adds complete Romanian language support while retaining all four
languages from the first public release.

## Languages

- English
- Deutsch
- Nederlands
- Български
- Română

Romanian is available throughout the launcher, Broadcast Scheduler, Public
Calendar editor, Library Cleaner, Silence Scanner, Auto Cutter, safety dialogs
and offline help.

## Installation

Extract the complete portable ZIP to a writable folder and start
`RadioBOSS Toolkit.exe`. Do not place the toolkit in protected Windows folders.

FFmpeg and FFprobe are expected in `C:\ffmpeg`.
