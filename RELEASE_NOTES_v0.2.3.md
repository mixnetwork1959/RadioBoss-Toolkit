# RadioBOSS Toolkit v0.2.3

The first complete portable release combines four independent RadioBOSS
broadcast and library utilities behind one launcher.

## Included

- Broadcast Scheduler
- RadioBOSS Library Cleaner
- Silence Scanner
- Auto Cutter

All tools remain separate processes, so the Scheduler and Silence Scanner can,
for example, run at the same time.

## Highlights

- Four interface languages: English, German, Dutch and Bulgarian
- Offline help in every included language
- Windows interfaces for Scanner and Cutter without console windows
- First-start selection of the RadioBOSS scheduler profile
- Cutter safety checks and preservation of original audio files
- Portable installation with no installer required

## Installation

Extract the complete ZIP to a writable folder and start
`RadioBOSS Toolkit.exe`. Do not extract it into protected Windows directories.

FFmpeg and FFprobe are expected in `C:\ffmpeg`.
