# RadioBOSS Toolkit v0.3.2

This maintenance update brings RadioBOSS SongSync Engine 1.7.2 into the portable Toolkit.

## Changes

- Windows OpenSSH SFTP uploads no longer open a CMD window
- Setup Wizard SFTP tests use the same hidden process handling
- SongSync continues to write normal status and errors to `songsync.log`
- Corrected the documented SongSync version and `config.py` filename
