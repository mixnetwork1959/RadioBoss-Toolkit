RadioBOSS Broadcast Scheduler

Kostenloses portables Werkzeug zur Prüfung von RadioBOSS-Sendeplänen und zur Erstellung eines öffentlichen Kalenders.

Erster Start

Wähle dein RadioBOSS-Scheduler-Profil (*.sdl). Das Programm speichert seine eigenen Einstellungen im Programmordner.

Funktionen

Prüfe geplante Events, Zeiten, Konflikte, Wochentage und längere Events. Nutze Filter für eine übersichtliche Eventliste und erstelle bei Bedarf einen öffentlichen Sendeplan/Kalender.

Portable Nutzung

Den kompletten Programmordner zusammenlassen und einen beschreibbaren Ort außerhalb von Program Files verwenden.

Sprache

Die Sprache kann unter Einstellungen → Sprache geändert werden.
