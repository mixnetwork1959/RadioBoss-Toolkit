RadioBOSS Toolkit

Portable broadcast and library tools for RadioBOSS.

Installation

Extract the complete folder to a writable location such as D:\RadioBOSS Toolkit. Do not use Program Files or Windows. Keep the complete folder structure together.

Broadcast Scheduler

On first start, select your RadioBOSS scheduler profile (*.sdl). The tool analyzes events, conflicts and the weekly calendar and can generate a public schedule website.

Library Cleaner

Select the RadioBOSS SQLite database or enter MySQL connection data. Scan first, review orphaned library entries, then clean. Music files and track records remain unchanged; a backup is created. The last selected SQLite database path is saved and restored on the next start.

Silence Scanner

Select a music folder and start the scan. Original audio files are never changed. Results are written to silence_report.csv.

Auto Cutter

Run Silence Scanner first and review its report.

Auto Cutter creates corrected copies in Music_Cut. It never overwrites original audio files.

Language and information

Choose English, German, Dutch or Bulgarian under Settings → Language. The setting is shared by all tools. Version and license information is available under Help → About.
