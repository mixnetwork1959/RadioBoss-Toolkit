RadioBOSS Broadcast Scheduler

Free portable scheduler analysis and public calendar tool for RadioBOSS.

First start

Select your RadioBOSS scheduler profile (*.sdl). The application stores its own settings in the program folder.

What it does

Review scheduled events, event timing, conflicts, weekday assignments and longer events. Use filters to focus the event list and generate a public schedule/calendar when required.

Portable use

Keep the complete application folder together and use a writable location outside Program Files.

Language

Choose the interface language under Settings → Language.
